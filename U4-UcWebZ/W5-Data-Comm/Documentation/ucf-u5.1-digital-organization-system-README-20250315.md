# Digital Organization System README

## Overview
The Digital Organization System is a comprehensive framework for organizing and managing cFish.io's digital assets according to the UcF (Unified cFish) standards. This system provides a structured approach to file naming, directory organization, and documentation management.

## Directory Structure
The system organizes files into department-based directories (U1-U7) according to their function:

- **U1-Administration**: Administrative files and governance documents
- **U2-Research**: Research, analysis, and planning documents
- **U3-Operations**: Standard operating procedures and operational documents
- **U4-Production**: Production-related files including WordPress
- **U5-Data**: Data management including documentation, synchronization, and backups
- **U6-Growth**: Marketing, business development, and growth initiatives
- **U7-Systems**: System infrastructure, scripts, and development tools

## File Naming Convention
Files should follow the UcF naming convention:

```
ucf-[department].[function]-[description]-[YYYYMMDD].[extension]
```

Example: `ucf-u5.1-digital-organization-system-README-20250315.md`

- **ucf-**: Standard prefix for all UcF-compliant files
- **[department]**: Department code (u1-u7)
- **[function]**: Function number within department
- **[description]**: Kebab-case description of file contents
- **[YYYYMMDD]**: Date in YYYYMMDD format (required for UcF compliance)
- **[extension]**: File extension
