# Keyboard Shortcut Testing

## Test Steps:

1. Open a terminal in Cursor (View > Terminal)
2. Make sure you're in the project root directory
3. Press `Ctrl+Alt+L` to test the pull shortcut
   - This should run `cursor-pull.bat`
   - If it works, you'll see the Git pull information

## Troubleshooting:

If the shortcut doesn't work:
1. Check if you've saved the keybindings.json file
2. Try restarting Cursor
3. Try opening a terminal first before using the shortcut
4. Make sure the cursor-pull.bat file exists in your project directory
