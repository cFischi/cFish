## Core Technology Infrastructure

cFish.io operates using a multi-layered technological framework:

- **WordPress**: Public-facing website (cfish.io) providing the digital storefront
- **ClickUp**: Project and task management system for operations/revenue tracking
- **Notion**: Knowledge management and documentation system
- **Vendasta**: Client management (CRM) and marketing automation

All systems are integrated through an automation layer that includes:
- Local/App Automation: ALLM/Flowise
- Browser/Cloud Automation: Automa, Harpa, Blaze.Today

## Digital Communication Framework

The communication system follows a funnel structure:

1. **UcF~Gate Funnel**: Manages incoming communication through synced email/calendar systems and 24/7 operational communication channels
2. **Gravity Funnel**: Provides value that pulls users into the ecosystem through content automation, live streaming, and interactive web elements
3. **Foundation Infrastructure**: Self-hosted media servers and local AI systems (tYFeAi)
