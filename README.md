# cFish.io WordPress Site

This repository contains the WordPress code for the cFish.io website.

## Development Workflow

1. **Development Environment:**
   - The site is developed locally in Cursor
   - Local WordPress development is done at: `C:\Users\Chris\cFish.io`

2. **WordPress Studio:**
   - Local WordPress Studio installation at: `C:\Users\Chris\Studio\cfishio`
   - Used for managing the site and pushing changes to the live site

3. **GitHub Repository:**
   - Changes are tracked in this repository
   - Main branch contains the production-ready code
   - Development is done in feature branches before merging to main

4. **Deployment:**
   - Develop locally in Cursor
   - Push changes to WordPress Studio
   - From WordPress Studio, update the live site on WordPress.com

## Important Notes

- The `wp-config.php` file is excluded from version control for security reasons
- The `.gitignore` file is configured to exclude unnecessary WordPress files

## Getting Started

1. Clone this repository
2. Set up a local WordPress development environment
3. Configure your local WordPress to use the appropriate database
4. Create feature branches for new development
5. Merge completed features to main
