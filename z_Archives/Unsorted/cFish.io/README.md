# cFish.io Digital Organization Structure

This repository follows tY & UcF best practices for digital organization.

## Directory Structure

### Main Categories (U-folders)

- **U1-Administration** - Business management and administration
- **U2-Research** - Research, analysis, and market intelligence
- **U3-Operations** - Day-to-day operations and procedures
- **U4-Production** - Content creation and production
- **U5-Data** - Data management, analytics, and synchronization
- **U6-Marketing** - Marketing campaigns and assets
- **U7-Systems** - Technical systems and development

### Special Directories

- **_Resources** - Templates, guidelines, and reference materials
- **_Archives** - Archived projects and documents
- **Documentation** - Technical and process documentation

## File Naming Conventions

- Use lowercase with hyphens for file names
- Prefix files with their category (e.g., u7-system-architecture.md)
- Include version in filenames when applicable (e.g., sop-v2.1.md)
