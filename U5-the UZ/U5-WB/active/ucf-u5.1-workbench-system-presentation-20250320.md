## 3. Key Implementation Features

### 3.1 Architecture

- **Master Workbench**:
  - Name: cFish-WB
  - Location: Root directory
  - Purpose: Organization-wide UcF projects and cross-departmental coordination

- **Department Workbenches**:
  - Count: 7
  - Names: U1-WB, U2-WB, U3-WB, U4-WB, U5-WB, U6-WB, U7-WB
  - Purpose: Department-specific projects and work items

- **Supporting Workbenches**:
  - Count: 5
  - Locations: wp-content, _Archives, _Resources, .cursor, Documentation
  - Purpose: Supporting area-specific work and projects

### 3.2 Standard Structure

- **active/** - Contains 1-3 items currently being worked on
- **WB-readme/** - Contains README files for items in the active folder
- **next-WB/** - Contains items to be worked on next after current active items are completed
- **next-readme/** - Contains README files for items in the next-WB folder
- **WB-memory.md** - Records all activities and changes in the workbench
- **WB-changelog.md** - Records significant structural or functional changes to the workbench
