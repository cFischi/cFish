# WordPress Development Agent Configuration

This directory contains specialized configuration files and resources for AI agents working on WordPress development projects. These resources help standardize agent workflows, improve efficiency, and ensure adherence to WordPress development best practices.

## Directory Structure

- `cheat-sheets/`: Quick reference guides for role-specific knowledge and patterns
- `prompt-templates/`: Standardized prompt structures for common development tasks

## Cheat Sheets

The cheat sheets provide specialized knowledge for different agent roles in the WordPress development workflow:

- `project-architect-cheatsheet.md`: System architecture, integration, and project planning
- `code-implementation-specialist-cheatsheet.md`: WordPress coding patterns and implementation
- `theme-development-specialist-cheatsheet.md`: WordPress theme development patterns
- `security-qa-analyst-cheatsheet.md`: Security review frameworks and testing protocols
- `documentation-specialist-cheatsheet.md`: Documentation standards and templates
- `plugin-integration-specialist-cheatsheet.md`: Plugin evaluation and integration patterns

Each cheat sheet includes:
- Core responsibilities for the role
- Common tasks and implementation patterns
- WordPress-specific code examples
- Handoff templates for cross-role collaboration
- Token optimization tips for efficient prompting

## Prompt Templates

The prompt templates provide structured formats for common WordPress development tasks:

- `project-architect-templates.md`: Architecture planning, component design, system integration
- `code-implementation-specialist-templates.md`: Plugin development, functions, hooks integration
- `theme-development-specialist-templates.md`: Theme architecture, templates, customization
- `security-qa-analyst-templates.md`: Security review, testing, performance analysis
- `documentation-specialist-templates.md`: API docs, user guides, inline documentation
- `plugin-integration-specialist-templates.md`: Plugin evaluation, implementation, customization

Each template collection includes:
- Standardized formats for common tasks
- Placeholders for required information
- Examples of proper usage
- Best practices for template customization

## Usage Guidelines

1. **Role Selection**: Choose the appropriate role based on the current development task
2. **Cheat Sheet Reference**: Review the cheat sheet for role-specific knowledge and patterns
3. **Template Selection**: Use the appropriate prompt template for the specific task
4. **Template Customization**: Fill in the placeholders with project-specific information
5. **Token Optimization**: Follow the token optimization tips for efficient processing

## Maintenance

These agent configuration files should be updated when:
- New WordPress best practices emerge
- Common development patterns change
- More efficient prompt structures are identified
- Additional role specializations are needed
