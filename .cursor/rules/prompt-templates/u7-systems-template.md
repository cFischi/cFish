# U7-Systems Department Template

## Department Overview

The U7-Systems department focuses on tYberius Designz, development, and technical direction for cFish.io. This template provides guidance for tasks related to system architecture, technical implementation, development standards, and specialized technical solutions.

## Key Department Functions

- Lead technical architecture and system design
- Establish development standards and best practices
- Implement specialized technical solutions
- Coordinate cross-platform technical integration
- Guide technical direction for all platforms
- Align all implementations with the Serve (U7) philosophical principle

## Task Categories

### Architecture Design

Tasks involving system architecture and technical design:

```
TASK: Design architecture for [System/Component]

Please develop a comprehensive architecture that:
1. Defines system components and their relationships
2. Establishes technical requirements and constraints
3. Identifies integration points with existing systems
4. Addresses performance and scalability considerations
5. Includes security and reliability requirements
6. Provides implementation guidance and recommendations

The architecture should balance immediate needs with long-term maintainability and scalability.
```

### Development Standards

Tasks involving development standards and best practices:

```
TASK: Create development standards for [Technology/Platform]

Please establish comprehensive development standards that:
1. Define coding conventions and patterns
2. Establish best practices for implementation
3. Identify recommended tools and libraries
4. Include performance optimization guidelines
5. Address security and quality assurance
6. Provide examples and reference implementations

The standards should ensure consistent, high-quality implementations while supporting developer productivity.
```

### Technical Integration

Tasks involving cross-platform technical integration:

```
TASK: Develop integration approach for [System A] and [System B]

Please create a technical integration strategy that:
1. Identifies integration requirements and objectives
2. Establishes technical approach and architecture
3. Defines data exchange formats and protocols
4. Addresses authentication and security considerations
5. Includes error handling and monitoring requirements
6. Provides implementation guidelines and examples

The integration should ensure reliable, efficient communication between systems while maintaining modularity.
```

### Specialized Solutions

Tasks involving specialized technical solutions:

```
TASK: Implement [Specialized Solution] for [Specific Need]

Please develop a specialized technical solution that:
1. Addresses the specific technical requirements
2. Leverages appropriate technologies and approaches
3. Integrates with existing systems and workflows
4. Optimizes performance for the specific use case
5. Includes appropriate monitoring and management
6. Provides documentation and maintenance guidance

The solution should solve the specific technical need while maintaining compatibility with the broader ecosystem.
```

## File Organization

U7-Systems files should be organized following the UcF naming convention:
`ucf-u7.[function]-[description]-[date].[extension]`

Example: `ucf-u7.4-integration-architecture-20250507.md`

Function codes:
1. Documentation
2. Configuration
3. Tools
4. Scripts/Development
5. Testing
6. Automation
7. Infrastructure
8. Integration
9. Miscellaneous

Files should be stored in appropriate subdirectories:
```
U7-Systems/
  Development/      # Development code and scripts
    Web/            # Web development files
    Scripts/        # Utility scripts
    Tests/          # Test files and frameworks
  Tools/            # Development and maintenance tools
  Configuration/    # System configuration files
  Documentation/    # Technical documentation
```
