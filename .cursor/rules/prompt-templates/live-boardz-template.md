## Session Workflow

### 1. Initialization Phase
- Executive Agent and Project Architect define overall approach
- All agents review assigned context materials
- Human Coordinator reviews and approves initial direction
- Project Architect creates detailed technical plan

### 2. Implementation Phase
- Implementation Engineer develops code based on approved plan
- QA Analyst reviews code quality and test coverage in parallel
- Project Architect verifies architectural alignment
- Documentation Specialist begins drafting documentation

### 3. Verification Phase
- QA Analyst conducts comprehensive testing
- Implementation Engineer addresses identified issues
- Project Architect validates system integration
- Documentation Specialist finalizes documentation

### 4. Handoff Phase
- All agents contribute to final deliverable review
- Documentation Specialist prepares handoff documentation
- Executive Agent validates alignment with strategic goals
- Human Coordinator provides final approval

## Human Intervention Points
- Initial review of Executive Agent and Project Architect recommendations
- Review of Implementation Engineer's approach before full implementation
- QA Analyst findings review and prioritization
- Final approval before handoff

## Communication Protocol
- Agents should state their role when responding
- Use structured format for handoffs between agents:
  ```
  [HANDOFF FROM: Agent Role]
  - Completed actions: [List what has been completed]
  - Current status: [Summary of current state]
  - Next steps: [What the receiving agent should focus on]
  - Context references: [Key files/documents to review]
  [HANDOFF TO: Next Agent Role]
  ```
- Decisions requiring consensus should use this format:
  ```
  [DECISION POINT]
  - Options: [List available options]
  - Recommendation: [Preferred option with rationale]
  - Implications: [Impact on other aspects of the project]
  [REQUEST FOR INPUT: Specific Agent or ALL]
  ```
