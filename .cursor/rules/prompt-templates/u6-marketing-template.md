# U6-Marketing Department Template

## Department Overview

The U6-Marketing department focuses on FischEYe production design, social media, and communications for cFish.io. This template provides guidance for tasks related to brand identity, content creation, client-facing materials, and social media management.

## Key Department Functions

- Lead communications and marketing initiatives
- Manage FischEYe production design
- Create and maintain brand identity
- Develop client-facing materials
- Coordinate social media presence
- Align all implementations with the Communicate (U6) philosophical principle

## Task Categories

### Brand Development

Tasks involving brand identity and guidelines:

```
TASK: Develop brand guidelines for [Project/Initiative]

Please create comprehensive brand guidelines that:
1. Define core brand elements (typography, color palette, imagery style)
2. Establish voice and tone for different communications
3. Provide logo usage specifications and variations
4. Include application examples across different media
5. Define brand storytelling principles
6. Incorporate alignment with Dreamflo ~ philosophy

The guidelines should ensure consistent brand expression while allowing appropriate flexibility for different contexts.
```

### Content Creation

Tasks involving content development for various channels:

```
TASK: Create content strategy for [Channel/Initiative]

Please develop a detailed content strategy that:
1. Identifies target audience and objectives
2. Establishes content themes and messaging priorities
3. Defines content types and formats
4. Creates an editorial calendar and publishing cadence
5. Includes success metrics and evaluation criteria
6. Provides governance for content creation and approval

The strategy should align with our brand identity while addressing specific audience needs and platform requirements.
```

### Documentation-as-Service

Tasks involving client-facing documentation development:

```
TASK: Create documentation template for [Document Type]

Please develop a professional documentation template that:
1. Incorporates our brand identity elements
2. Establishes consistent structure and organization
3. Includes appropriate typography and layout
4. Defines content sections and information hierarchy
5. Provides guidance for authors and contributors
6. Supports different export formats (PDF, HTML, print)

The template should exemplify our documentation-as-service offering while ensuring usability and professionalism.
```

### Social Media Management

Tasks involving social media strategy and implementation:

```
TASK: Develop social media campaign for [Initiative/Event]

Please create a comprehensive social media campaign that:
1. Establishes campaign objectives and success metrics
2. Identifies platforms and channel-specific approaches
3. Develops key messaging and content themes
4. Creates a posting schedule and cadence
5. Includes engagement strategies and response guidelines
6. Provides analytics and reporting framework

The campaign should reflect our brand voice while optimizing for each platform's unique characteristics.
```

## Documentation Standards

All U6-Marketing documentation should follow these standards:

- Use clear, engaging language appropriate for the target audience
- Include visual elements that reflect brand identity
- Maintain consistent formatting and structure
- Provide examples and applications where appropriate
- Include distribution and usage guidelines
- Follow the memory file update format:

```markdown
## [Title] (MM-DD-2025)
- [Bullet points with key information]
- [More bullet points as needed]

_Updated MM-DD-2025 | AI: Cursor (Claude 3.7 Sonnet)_
```

## File Organization

U6-Marketing files should be organized following the UcF naming convention:
`ucf-u6.[function]-[description]-[date].[extension]`

Example: `ucf-u6.4-brand-guidelines-20250507.md`

Function codes:
1. Documentation
2. Configuration
3. Tools
4. Scripts/Development
5. Testing
6. Automation
7. Infrastructure
8. Integration
9. Miscellaneous

Files should be stored in appropriate subdirectories:
```
U6-Marketing/
  Branding/         # Brand identity and guidelines
  Media/            # Media assets and resources
  Campaigns/        # Marketing campaign materials
  Social/           # Social media content and planning
  Content/          # Content creation and management
  Analytics/        # Marketing analytics and reporting
```
