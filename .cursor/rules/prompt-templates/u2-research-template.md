# U2-Research Department Template

## Department Overview

The U2-Research department focuses on AI integration, research and development, and tYFeAiz collaboration for cFish.io. This template provides guidance for tasks related to artificial intelligence, innovation, multi-agent collaboration, and emerging technology research.

## Key Department Functions

- Lead AI integration across all cFish.io platforms
- Manage tYFeAiz collaboration framework
- Research emerging technologies for potential integration
- Develop innovative solutions for client needs
- Establish AI best practices and patterns
- Align all implementations with the Mind (U2) philosophical principle

## Task Categories

### AI Integration

Tasks involving artificial intelligence implementation and optimization:

```
TASK: Implement [AI Feature] for [Platform/Component]

Please develop a comprehensive AI integration plan that:
1. Identifies appropriate AI models and technologies
2. Establishes integration architecture
3. Defines data requirements and processing
4. Addresses performance considerations
5. Includes monitoring and evaluation metrics
6. Provides fallback mechanisms for resilience

The implementation should leverage our tYFeAiz framework and follow our established AI best practices.
```

### Multi-Agent Collaboration

Tasks involving tYFeAiz "Live Boardz" multi-agent collaboration sessions:

```
TASK: Coordinate a Live Boardz session for [Project/Feature]

Please facilitate a Live Boardz session that:
1. Assembles appropriate specialized agents for this task
2. Establishes clear roles and responsibilities
3. Coordinates efficient information sharing
4. Manages decision-making processes
5. Documents session outcomes and learnings
6. Identifies follow-up actions and assignments

The session should follow our established tYFeAiz collaboration framework with appropriate human-in-the-loop coordination.
```

### Emerging Technology Research

Tasks involving research into new technologies and approaches:

```
TASK: Research [Technology/Approach] for potential implementation

Please conduct a comprehensive research analysis that:
1. Evaluates the technology's capabilities and limitations
2. Assesses alignment with our strategic objectives
3. Identifies potential implementation approaches
4. Explores integration with existing systems
5. Analyzes resource requirements and constraints
6. Recommends next steps for exploration or implementation

The research should consider both technical feasibility and strategic alignment with our April 2025 relaunch objectives.
```

### Local LLM Implementation

Tasks involving local language model implementation and optimization:

```
TASK: Optimize local LLM implementation for [Specific Task/Function]

Please develop a local LLM optimization plan that:
1. Evaluates model performance for the target task
2. Recommends model selection and configuration
3. Develops prompt optimization strategies
4. Addresses hardware resource allocation
5. Implements caching and optimization techniques
6. Defines evaluation metrics for performance validation

The optimization should balance performance with resource constraints in our garage-based operations environment.
```

## Documentation Standards

All U2-Research documentation should follow these standards:

- Use clear technical language with appropriate definitions
- Include methodology descriptions and approach rationale
- Document model selections and configuration parameters
- Provide benchmark results and performance metrics
- Include references to research sources and documentation
- Follow the memory file update format:

```markdown
## [Title] (MM-DD-2025)
- [Bullet points with key information]
- [More bullet points as needed]

_Updated MM-DD-2025 | AI: Cursor (Claude 3.7 Sonnet)_
```

## File Organization

U2-Research files should be organized following the UcF naming convention:
`ucf-u2.[function]-[description]-[date].[extension]`

Example: `ucf-u2.4-agent-framework-20250507.py`

Function codes:
1. Documentation
2. Configuration
3. Tools
4. Scripts/Development
5. Testing
6. Automation
7. Infrastructure
8. Integration
9. Miscellaneous

Files should be stored in appropriate subdirectories:
```
U2-Research/
  Models/           # Local AI model configuration
  Frameworks/       # AI framework implementation
  Analysis/         # Research analysis and reports
  Prompts/          # Specialized prompt libraries
  Agents/           # Agent configuration and definitions
  Experiments/      # Experimental implementations
  Documentation/    # Research documentation
```
